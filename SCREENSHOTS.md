# Як додати скріншоти до проєкту

## Коротко

1. Зроби скріни 1600×1200.
2. Поклади їх у `public/projects/<slug>/`.
3. Пропиши шляхи в `screenshots: [...]` у файлі проєкту.
4. Перевір у `npm run dev`.

## 1. Куди класти файли

```
public/projects/<slug>/
```

`<slug>` — це ім'я файлу проєкту з `src/content/projects/` без `.md`:

| Файл проєкту | Папка для скріншотів |
|---|---|
| `src/content/projects/sistema.md` | `public/projects/sistema/` |
| `src/content/projects/emma-j-shipley.md` | `public/projects/emma-j-shipley/` |

Назви файлів довільні, але краще короткі латиницею, без пробілів: `home.jpg`, `product.jpg`, `cart.jpg`.

## 2. Як прописати їх у проєкті

У файлі проєкту (наприклад `src/content/projects/sistema.md`) заповни поле `screenshots`:

```yaml
screenshots: ["/projects/sistema/home.jpg", "/projects/sistema/product.jpg", "/projects/sistema/cart.jpg"]
```

- Шлях починається з `/projects/...`, **без** `public`.
- Порядок важливий: **перший файл — обкладинка картки**.
- Якщо лишити `screenshots: []`, на сайті буде сіра заглушка `[Screenshot: …]`.

## 3. Де вони з'являться

Це залежить від поля `level` у файлі проєкту:

| `level` | Що показується |
|---|---|
| `"case"` | Перший скрін — на картці (головна та `/projects/`). Усі скріни — на сторінці кейсу, по три в ряд. |
| `"card"` | Тільки перший скрін — на картці на `/projects/`. |
| `"archive"` | Скріни ніде не показуються: такий проєкт — лише рядок у таблиці Archive. |

Картка обрізає обкладинку до пропорції **4:3**. Тому знімай одразу 4:3, і нічого не обріжеться.

## 4. Як зробити скрін потрібного розміру (Chrome)

1. Відкрий сайт клієнта, натисни `Cmd + Option + I` (DevTools).
2. Увімкни режим пристрою: `Cmd + Shift + M`.
3. Угорі вибери **Responsive** і введи розмір **1600 × 1200**.
4. `Cmd + Shift + P` → набери `screenshot` → **Capture screenshot**.

Файл збережеться в «Завантаження» як `.png`.

Для мобільної версії сайту бери розмір **390 × 844**, але на обкладинку його не став: він вузький, і картка сильно його обріже.

## 5. Як стиснути файл

PNG зі скріна часто важить 1–3 MB, а на сайт треба до ~300 KB. На Mac це робиться в Терміналі однією командою, без додаткових програм:

```bash
sips -s format jpeg -s formatOptions 80 -Z 1600 ~/Downloads/скрін.png --out public/projects/sistema/home.jpg
```

- `formatOptions 80` — якість JPEG (80 зазвичай досить).
- `-Z 1600` — найбільша сторона буде 1600 px.

Команду запускай з папки сайту (`cd ~/Desktop/site`).

Якщо хочеш формат `.webp` (він ще легший), стисни файл на [squoosh.app](https://squoosh.app) і поклади результат у ту саму папку.

## 6. Перевірка

```bash
npm run dev
```

Відкрий http://localhost:4321/projects/ і подивись, чи на картці правильна обкладинка. Для `case` відкрий ще сторінку кейсу.

Якщо шлях написаний з помилкою, скрін не з'явиться: замість нього буде порожня рамка. Перевір, що назва папки й файлу збігаються до літери, бо регістр важливий: `Home.jpg` ≠ `home.jpg`.

## Чого не робити

- **Не додавай скріни NDA-проєктів** (`nda: true`). Навіть без назви дизайн можна впізнати.
- **Не клади фото з телефона без очистки.** У них зашиті GPS-координати, а все з `public/` публікується. Скріни з браузера таких даних не мають.
- **Не додавай особисті дані зі скріна:** адмінку Shopify, замовлення, імена й емейли клієнтів, тестові картки. Знімай тільки вітрину.
